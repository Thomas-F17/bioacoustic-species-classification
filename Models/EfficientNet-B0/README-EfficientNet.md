# EfficientNet-B0 iNatSounds

This documents the EfficientNet-B0 training run on the iNaturalist Sounds Dataset (iNatSounds, NeurIPS 2024).

## Setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/cvl-umass/iNatSounds.git
cd iNatSounds
pip install torch torchvision torchaudio numpy scikit-learn tqdm matplotlib pandas Pillow opencv-python-headless
```

## Modifications Made

### models.py

EfficientNet-B0 and EfficientNet-B2 were added to the `get_model()` function and `hidden_dim_dict`. The classifier head replacement for EfficientNet is:

```python
weights = torchvision.models.EfficientNet_B0_Weights.IMAGENET1K_V1 if pretrained else None
model = torchvision.models.efficientnet_b0(weights=weights)
model.classifier[1] = nn.Linear(1280, output_dim)
```

### main.py

In both `run_train` and `run_eval`, the GeoModel instantiation was replaced with:

```python
geo_model = None
```

This disables geographic prior filtering, which requires separate SINR pretrained weights that were not available. No other files were modified.

## Data

Training used **100% of the iNatSounds dataset**:

| Split | Files | Species |
|-------|-------|---------|
| Train | 137,012 | 5,569 |
| Val | 45,698 | 1,212 |
| Test | 49,527 | 1,212 |

The dataset was downloaded as a single `spectrograms.tar` archive containing preprocessed mel-spectrogram `.npy` files and JSON split files (`train.json`, `val.json`, `test.json`). The spectrograms were generated by the dataset authors using a Hann window of 512 samples, stride 128, 1024-point FFT and 128 logarithmically spaced mel bins mapping frequencies in the range 50 Hz–11.025 kHz. Each spectrogram was stored as a uint8 grayscale image and duplicated to 3 channels at load time.

During training, one random 3-second window (512 pixels wide) is sampled per recording per epoch. During evaluation, all 3-second windows (strided by 1.5 seconds) are extracted from each recording and predictions are averaged to produce file-level scores. Predictions are masked to the 1,212 evaluation species.

## Training Command

```bash
python main.py \
    --spectrogram_dir ~/data/spectrograms \
    --json_dir ~/data \
    --model efficientnet_b0 \
    --optim nesterov \
    --lr 0.05 \
    --wd 1e-5 \
    --batch_size 128 \
    --epochs 50 \
    --eval_freq 5 \
    --pretrained \
    --mixup \
    --sound_aug \
    --seed 0 \
    --exp_name efficientnet_b0_run \
    --mode train
```

## Key Hyperparameters

| Parameter | Value |
|-----------|-------|
| Model | EfficientNet-B0 (~5.3M params) |
| Pretrained weights | ImageNet-1K V1 (torchvision) |
| Epochs | 50 |
| Batch size | 128 |
| Optimiser | SGD with Nesterov momentum (0.9) |
| Learning rate | 0.05 |
| Weight decay | 1e-5 |
| LR schedule | 5-epoch linear warmup + cosine annealing |
| Mixup | Enabled (alpha=1.0, beta distribution) |
| Sound augmentation | Frequency masking (15 bins) + time masking (15 bins) |
| Loss | Cross-entropy (multiclass) |
| Evaluation masking | Masked to 1,212 val/test species |

The training protocol is identical to the original iNatSounds paper (Chasmai et al., 2024). The only change is the backbone architecture, so all augmentations, optimiser settings, learning rate scheduling and evaluation procedures are kept the same to ensure a fair comparison.

## Training Infrastructure

Training was performed on Thunder Compute using a single NVIDIA A100 (80GB) GPU. Total training time was approximately 9 hours for 50 epochs, with validation evaluated every 5 epochs.

## Model Weights

## Results

Best validation performance was at epoch 49. Test set results (sound-avg, class-averaged):

| Metric | Value |
|--------|-------|
| mAP | 66.74% |
| mF1 | 68.60% |
| Top-1 | 55.28% |
| Top-5 | 76.56% |
| ROC-AUC | 99.15% |

### Comparison to paper baselines (test set, no geo-priors)

| Model | Params | Top-1 | Top-5 | mAP |
|-------|--------|-------|-------|-----|
| MobileNet-V3 (paper) | 6.24M | 49.10 | 69.50 | 60.00 |
| ResNet-50 (paper) | 26.77M | 52.60 | 74.30 | 62.80 |
| ViT-B-16 (paper) | 87.02M | 53.60 | 74.30 | 64.40 |
| **EfficientNet-B0 (ours)** | **5.3M** | **55.28** | **76.56** | **66.74** |

EfficientNet-B0 outperforms all three paper baselines on every metric, including ViT-B-16 which has over 16× more parameters.

## Notes

- Geo-prior evaluation was not performed due to unavailability of SINR model weights
- Results are from a single seed (seed=0); the paper reports mean ± std across 3 seeds
- The model was still improving at epoch 49, suggesting marginal gains could be achieved with longer training
