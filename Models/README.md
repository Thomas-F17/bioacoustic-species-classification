# Models

This folder contains all the trained model runs on iNatSounds (one subfolder per 
backbone), the cross-dataset evaluation on SSW60, and a short notebook that reports the 
parameter count of each architecture.

## Contents

- `ConvNeXt/`
- `EfficientNet-B0/`
- `MobileNetV3-Large/`
- `Swin-V2-B/`
- `Testing on SSW60/`
- `parameter_counts.ipynb`
